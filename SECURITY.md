# Security & Vulnerability Policy
## Profile & Ecosystem Architecture

---

### 1. Overview
The **jeanlaris/jeanlaris** repository acts as the sovereign core and profile hub for the ecosystem. Security is maintained to protect architectural assets, configuration consistency, and documentation integrity.

---

### 2. Reporting a Vulnerability
We prioritize system security and data precision. If you identify a security concern or vulnerability:

* **Direct Notification**: Open a private security advisory or contact the repository maintainer directly.
* **Details Required**: Provide a comprehensive description, replication steps, and potential system impact.
* **Response Window**: Security advisories are triaged immediately upon submission.

---

### 3. Supported Versions
Active maintenance and security updates apply solely to the latest commit on the main branch.

| Version / Branch | Supported Status |
| :--- | :--- |
| `main` (Active) | **Supported** |
| Legacy Branches | Not Supported |

---

### 4. Governance & Compliance
All profile updates and documentation commits must adhere to the high-performance structural standards of our organization.
